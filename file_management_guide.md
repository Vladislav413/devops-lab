Руководство по операциям с файлами и директориями Linux
Базовый инструментарий
mkdir -p [путь] — создание цепочки директорий любой глубины.
touch [файл] — создание пустого файла или обновление timestamp.
cp [откуда] [куда] — копирование файлов/папок. Флаг -a обязателен для сохранения прав, владельцев и timestamps.
mv [откуда] [куда] — перемещение или переименование (быстрая смена записи в dentry).
rm -rf [путь] — рекурсивное удаление папок/файлов без запроса подтверждений.
cat [файл] — быстрый вывод содержимого небольших файлов.
less [файл] — постраничный просмотр крупных логов без полной загрузки в ОЗУ.

Практический регламент обслуживания
1. Создание структуры: mkdir -p ~/app_demo/logs
2. Резервное копирование конфига перед изменением: cp -a app.conf app.conf.bak
3. Ротация текстового лога: mv app.log app.log.old && touch app.log
4. Очистка временных файлов: rm -f debug.tmp
