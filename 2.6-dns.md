# DNS Troubleshooting Cheat Sheet

## Основные конфигурационные файлы (Linux)
* `/etc/hosts` — Локальная таблица имен (высший приоритет). Система проверяет этот файл до обращения к внешним серверам. Используется для жесткой привязки IP к домену (например, для локального тестирования).
* `/etc/resolv.conf` — Конфигурация DNS-клиента. Содержит IP-адреса DNS-серверов (nameserver), к которым обращается система для разрешения имен.

## Типы DNS-записей
* **A (Address):** Привязывает домен к IPv4-адресу (для IPv6 используется AAAA).
* **CNAME (Canonical Name):** Псевдоним. Ссылается на другое доменное имя. Нельзя применять к корневому домену (apex domain).
* **MX (Mail Exchange):** Указывает на почтовые серверы домена (имеют приоритеты).
* **TXT (Text):** Текстовые данные, часто используются для подтверждения владения доменом и настроек безопасности почты (SPF, DKIM).

## Основные команды (dig)
Запрашивает A-запись домена по умолчанию:
`dig example.com`

Выводит только целевой результат (IP-адрес) без служебной информации (удобно для bash-скриптов):
`dig +short A example.com`

Прямой запрос к конкретному DNS-серверу (например, 8.8.8.8) в обход локального кэша провайдера. Помогает проверить, обновились ли записи глобально (учитывая TTL):
`dig @8.8.8.8 example.com`

Получение почтовых серверов с фильтрацией вывода (удаление комментариев и пустых строк):
`dig example.com MX +short | grep -v '^;'`
