# Текстовые редакторы Nano и Vim

### Nano
- Ctrl + O (Enter) — сохранить файл
- Ctrl + X — выйти
- Ctrl + K — вырезать строку
- Ctrl + U — вставить строку

### Vim
- i — войти в режим редактирования (Insert mode)
- Esc — вернуться в режим команд (Normal mode)
- :wq — сохранить и выйти
- :q! — принудительно выйти без сохранения
- dd — удалить (вырезать) строку
- gg / G — прыжок в начало / конец файла
- :%s/старое/новое/g — автозамена во всем файле
