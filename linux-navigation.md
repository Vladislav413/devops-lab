Навигация по файловой системе Linux и FHS                                                                 Ключевые директории FHS
/etc — Конфигурационные файлы ОС и сервисов 
/var/log — Логи системы и приложений 
/var/lib — Состояние сервисов и данные СУБД (MySQL, PostgreSQL, Docker).
/home / /root — Домашние каталоги пользователей и root.
/bin, /usr/bin — Исполняемые файлы и системные утилиты.
/tmp — Временные файлы (очищаются при перезагрузке).
Горячие команды навигации
pwd — Вывести текущий абсолютный путь.
cd - — Быстрый возврат в предыдущую директорию.                                                             cd ~ — Переход в домашний каталог пользователя ($HOME).
ls -lah — Полный список файлов с размерами в KB/MB/GB и скрытыми файлами.                                                                                                                                                  tree -L 2 /var — Дерево каталогов с ограничением глубины вывода.                                        
                                                                                                                                                                       Пути
Абсолютный: От корня / (например, /etc/nginx/nginx.conf). Работает из любой точки.                                                                                                                       Относительный: От текущей рабочей директории (например, nginx/nginx.conf, если находишься в /etc).
